Marginalia

prototype 1 of 5 · agent panel for the text view

The panel lives in the right margin of the reading column, 260px wide to match the sidebar, with no card, no background and no badges. A monitoring surface that demands attention has already failed, so this one is built from typeset text on the page background and one hairline. It is marginalia: you absorb it while reading something else, and you read it properly only when you decide to.

The idea I want judged is the spine. Each entry's 2px left rule is the agent's Claude Code colour, and indenting that same rule is how nesting is drawn, so identity and the tree cost one stroke between them. Workflow runs get a grey spine instead of a coloured one, which is the whole distinction between a run and an ad-hoc agent. Above it sits the tally, one tick per agent, where a dim tick is one that has not written in a while and a short one is finished. Six running with one quiet is legible from that row alone, without reading a word.

There is no spinner anywhere. Peripheral vision is most sensitive to movement, so the only things that change are the elapsed digits and the tool name, and both of those are information. Silence is shown by letting the activity line fade as it ages, which puts the fact on screen without the panel ever judging it.

The risk I took is discoverability. With no chrome there is no button to press, so clicking an agent is carried by a faint chevron, a hover tint and keyboard focus. With more time I would test whether that chevron is enough, tune the fade curve for silence against real sessions rather than my guess at it, and give the narrow strip the same drill-in the wide margin has instead of an expand-in-place list.
