Where it goes. In the timeline, at the moment the spawn happened, in the same 860px column as every other row. A live block is an ordinary tool row that has not finished being written, so it uses the same glyph, the same 11px noun and the same fold as a finished Read, and when the agents settle it collapses into exactly the ticked row the text view shows today. Nothing appears and nothing disappears. The story just carries on underneath it, which is why the assistant keeps writing while the workflow runs.

The idea I want judged is the running head. Live work in a scrolling transcript is unreachable the second you scroll away, and the usual fix is a floating panel, which is a second place the same facts have to live and stay in sync. Instead one line appears at the top of the timeline, and only while every live block is off screen, carrying the same counts and the same current tool in compressed form, with an arrow saying which way to go. It is the block wearing one line, not a copy of it. Scroll the block back into view and the line is gone.

The detail I would point at is the tool trail, the eight dim letters sitting in front of the arrow on every agent row. Tool count as a number tells you almost nothing. The same count as a readable run of letters tells you this agent has been grepping for a while and that one just started, and it costs no extra data, because the agent transcript already holds every tool name. It also gives the block its only motion that carries meaning: a letter shifts in when a tool changes. There is no spinner anywhere on this page, because a spinner claims an agent is alive and the transcript cannot tell me that. The only two things that move every second are elapsed and the age of the current call.

What I would fix with more time. The workflow phase header should stick while you read a 16 row phase, so you never lose which phase you are in. Two agents open at once should sit side by side instead of stacking. And the seven identity hues are only proven against this theme, so they need a pass on the eight I did not render.
